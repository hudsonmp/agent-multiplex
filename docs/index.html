agent-multiplex

Drive claude and gemini side-by-side in parallel git worktrees on the same repo. One browser tab, two PTYs, transcripts saved to disk.

install

$ git clone https://github.com/hudsonmp/agent-multiplex.git
$ cd agent-multiplex
$ npm install                # compiles node-pty
$ npm run dev                # backend :4040, frontend :5173

Open localhost:5173. Requires Node 20+, git, and on macOS xcode-select --install for the node-pty build.

agents

claude
Anthropic's Claude Code. Install per docs.claude.com.
gemini
Google's open-source gemini-cli. npm i -g @google/gemini-cli.

If only one is on $PATH, the other pane shows exited (127) and the rest of the session works. The server augments $PATH with ~/.local/bin, ~/.npm-global/bin, and /opt/homebrew/bin.

run a session

  1. Enter the absolute path of a git repo. Click load branches.
  2. Pick a base branch. Accept the default mux/<agent>-<timestamp> agent branch names.
  3. Launch. Two worktrees are created at <repo>-mux-claude-<id>/ and <repo>-mux-gemini-<id>/. Each agent boots in its own.
  4. Type into either pane. Drag the divider. Both terminals reflow on resize.
  5. Click close session to kill PTYs, remove worktrees, and seal the manifest. Logs are kept.

comparing the two agents

Give both panes the same prompt. Watch where they diverge in approach, tool use, file edits, and final answer. After closing:

$ ls ~/.agent-multiplex/sessions/<id>/
manifest.json   claude.log   gemini.log

# Replay a transcript with timestamps stripped
$ cat claude.log | perl -pe 's/\x1e\d+\x1e//g'

# Diff what each agent actually committed
$ git -C <repo> diff main..mux/claude-<timestamp>
$ git -C <repo> diff main..mux/gemini-<timestamp>

# Or diff the two agents directly against each other
$ git -C <repo> diff mux/gemini-<timestamp>..mux/claude-<timestamp>

The \x1e byte (ASCII Record Separator) frames each timestamp. It does not appear in ANSI escape sequences or normal terminal output, so timestamps strip cleanly without colliding with content.

same

notes

  • Server binds to 127.0.0.1. No auth. Single-user, single-laptop.
  • node-pty needs build tools: xcode-select --install on macOS, apt-get install build-essential python3 on Linux.
  • If the backend dies mid-session, worktrees outlive it. Clean up with git worktree list then git worktree remove --force <path>.
  • Closing a session does not delete branches. Drop them with git branch -D mux/<agent>-<timestamp>.
